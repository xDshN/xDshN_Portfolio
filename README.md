# Андрей Варнавский — инженер прямого эфира

Портфолио: https://xdshn.github.io/xDshN_Portfolio/

Статический сайт без сборки: `index.html`, `styles.css`, скрипты и `assets/`.
Живой голографический фон и формы рисуются на WebGL2 (`holo.js`, `forms.js`),
заставка со стингером — `motion.js`, каскадное появление блоков и облака под
ними — `app.js`.

При пуше в `main` GitHub Actions публикует файлы на GitHub Pages
(`.github/workflows/deploy-pages.yml`).

Прошлая версия сайта на Next.js сохранена в ветке `old-nextjs`.
