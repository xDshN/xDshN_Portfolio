# Передача проекта Claude

> GitHub Pages edition: проект настроен на `output: "export"`. Не удаляйте
> `NEXT_PUBLIC_BASE_PATH`, функцию `assetPath` и workflow в `.github/workflows` —
> они обеспечивают работу изображений, видео и Next.js-файлов внутри подпути репозитория.

## Что это

Полный исходный проект портфолио Андрея Варнавского: десктопная и мобильная версии, все локальные изображения, видео, интерактивный дипломный раздел и стили.

- Рабочий сайт: https://andrey-broadcast-portfolio.bubsishn.chatgpt.site
- Снимок исходников: commit `4568ea4640ad8d63a3959c53c89932543d01d866`
- Стек: React 19, Next.js 16, TypeScript, CSS
- Требуемая версия Node.js: `>=22.13.0`
- Переменные окружения и внешняя база данных не требуются.

## Быстрый запуск

```bash
npm ci
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
```

Статическая сборка и работа из подпути GitHub Pages проверены 31 августа 2026 года.

## С чего начать Claude

1. Прочитать этот файл целиком.
2. Изучить `app/page.tsx`, затем `app/globals.css` и `app/layout.tsx`.
3. Запустить проект и сохранить существующую визуальную систему до получения конкретной задачи на редизайн.
4. После правок обязательно проверить desktop и mobile, а затем выполнить `npm run build`.

## Структура страницы

Порядок секций сейчас такой:

1. Первый экран
2. Профиль
3. Компетенции
4. Графика / видеокейсы
5. Дипломный проект
6. Выбранные проекты
7. Профессиональный путь
8. Контактный блок

Якоря: `#top`, `#profile`, `#capabilities`, `#graphics`, `#thesis`, `#projects`, `#path`, `#contact`.

## Критичные визуальные решения

- Основная палитра: почти чёрный, тёмно-синий, фиолетовый, холодный голубой и дозированный неон.
- Фон должен оставаться неоднородным: градиенты, мягкие световые поля, сетки и органические формы.
- Типографика уже сведена в единую систему. Не смешивать случайные семейства и не уменьшать основной текст до нечитаемого размера.
- Заголовки секций выровнены влево.
- Портрет должен оставаться визуально центрированным внутри своей карточки; подпись `SYSTEMS ONLINE` не должна уходить за правую границу.
- Контактный заголовок «Обсудим ваш проект?» использует один шрифт и должен помещаться без обрезания букв и без искусственных прямоугольных подложек.
- В мобильной версии приоритеты: читаемость, удобные touch-цели, отсутствие горизонтального скролла и сохранение ощущения дорогого визуального продукта.
- Уважать `prefers-reduced-motion`.

## Интерактивность, которую нельзя случайно сломать

- Мобильное меню и блокировка прокрутки при его открытии.
- Видеокейсы графики: воспроизведение, постеры и переключение выбранного кейса.
- Интерактивная схема дипломного проекта и переключение этапов.
- Открытие иллюстраций диплома в модальном просмотре.
- Закрытие модальных элементов по кнопке, клику по фону и клавише Escape.
- Все внутренние ссылки должны вести к существующим якорям.

## Ассеты

Все изображения и видео уже лежат локально в `public/assets/`. Не заменять их случайными стоками или сгенерированными картинками без прямой просьбы. Пути в данных начинаются с `/assets/...`, но при выводе должны проходить через `assetPath(...)`, иначе они сломаются в подпапке GitHub Pages.

Самые важные видео:

- `public/assets/graphics/student-of-the-year.mp4`
- `public/assets/graphics/miss-and-mister.mp4`
- `public/assets/graphics/kvn.mp4`
- `public/assets/graphics/final-graphic.mp4`

## Технические примечания

- Проект использует клиентский компонент в `app/page.tsx` (`"use client"`).
- Основная логика и стили намеренно собраны компактно в двух крупных файлах. Разносить их на компоненты можно, но только без изменения поведения и визуального результата.
- `npm run build` создаёт статический сайт в `out/`.
- Папки `node_modules`, `dist`, `.git`, `.sites-runtime`, `.wrangler` и другие генерируемые данные в архив не включены. Они восстанавливаются командами установки и сборки.
- Секретов и приватных ключей в экспорт не добавлено.
